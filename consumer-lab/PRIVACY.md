# Orbit privacy disclosure

Orbit is a classroom consumer analysis tool. Browsing history, imported user-authored conversation excerpts, order records, product catalogs, category scores, and feedback are processed only in the current dashboard tab's memory. The extension reads only after Chrome permission is approved and the user starts an analysis. Data is not sold, shared, monetized, uploaded to an AI provider, or sent to the developer. No analytics are installed. No account is required. No records persist by default. Close or reload the tab to clear the session; individual records and sources can also be removed. Catalog images contact their source only after an explicit click; source links open third-party retailers under their own privacy policies. GitHub Pages receives routine page/asset requests.

History permission is optional and is requested in the extension popup. Chrome's permission grants broader capability, including modification, but Orbit uses read-only search/getVisits calls. Chosen analysis periods are 7, 30, or 90 days. Limits: 5,000 URLs and 100,000 visits, with truncation disclosure. The extension does not read credentials, cookies, passwords, private account contents, or incognito data. It transfers only visited page titles, sanitized URLs, and visit times to the authorized dashboard path on connornee-1.github.io. Query strings/fragments are removed, but titles and paths may still contain personal information.

Revoke permission using the extension popup, Chrome extension settings, or the dashboard. Revocation prevents future reads; previously transferred in-memory data must also be cleared or the tab reloaded. Uninstalling the extension does not delete Chrome's original history. Orbit never modifies original Chrome history or source files.

Sensitive-keyword records are excluded from profiling. Filtering is imperfect; no sensitive-characteristic classifications are made. Keyword associations and scores are tentative, not psychological measurements. User-role conversation imports cannot reliably identify unmarked quotations. Inspect evidence and remove unwanted records.

Changes to this policy require corresponding code changes and updated distribution review. Before Chrome Web Store submission, the publisher must provide a public support contact, verify the hosted policy URL, and make accurate Store declarations matching this code.
